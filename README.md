# 🐞 BugSense AI

### The AI-Powered Diagnostic Workspace for Developers

---

## 🚀 Overview

BugSense AI is an intelligent debugging workspace that transforms vague bug reports into actionable insights. It helps developers quickly identify root causes, generate fixes, and validate solutions — all in one unified interface.

---

## 🧠 Problem

Developers spend hours debugging issues due to:

* Unclear bug reports
* Complex logs
* Lack of structured debugging workflow

This leads to wasted time and slower development cycles.

---

## 💡 Solution

BugSense AI uses AI to:

* Analyze bug reports, logs, and code
* Generate reproduction steps
* Identify root causes
* Suggest fixes with code-level insights
* Create test cases automatically

---

## 🔥 Features

* 🧪 **Reproduction Steps Generator**
* 🌳 **Root Cause Analysis (with probability)**
* 💡 **Code Fix Suggestions (diff view)**
* 🔄 **System Flow Visualization**
* 🧪 **Auto Test Case Generation**
* 🚨 **Bug Severity Classification**
* 🧠 **Persistent Session History (Firebase)**
* 🔐 **Multi-Auth (Email, Google, Guest)**

---

## 🛠️ Tech Stack

* **Frontend:** React + Tailwind CSS + Framer Motion
* **Backend:** Node.js (API routes)
* **Database:** Firebase (Firestore)
* **Authentication:** Firebase Auth
* **AI Engine:** Google Gemini API

---

## ⚙️ How It Works

1. User inputs bug report, logs, and code
2. AI analyzes the data
3. Generates:

   * Reproduction steps
   * Root cause
   * Fix suggestions
   * Test cases
4. Stores session for future reference
